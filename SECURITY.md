# Security Policy

## Supported Versions

We provide security updates only for actively supported versions.  
Older versions may not receive patches.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not open a public issue**.  
Instead, report it responsibly by emailing us:

- **Email:** support@oursprivacy.com  

Please include as much detail as possible:
- Steps to reproduce
- Impact of the vulnerability
- Any suggested fixes

We aim to respond within **72 hours**, and will work with you on a timeline for public disclosure.

## Disclosure Policy

- We will acknowledge receipt of your report within 3 business days.
- We will provide an initial assessment within 7 business days.
- We will notify you when the fix is released and credit you (if desired).

## Scope

This policy applies to:
- All repositories under this GitHub organization/account.
- All code, documentation, and configurations published here.

## Safe Harbor

We will not pursue legal action against security researchers who:
- Report vulnerabilities in good faith.
- Avoid privacy violations, data destruction, or service disruption.
- Provide us with a reasonable amount of time to remediate before public disclosure.
